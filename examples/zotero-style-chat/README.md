# Zotero 风格研究助手

在分析页面边读论文边提问，用已有的 MiniMax 或其他模型整理研究笔记。

适用于 EMP Web 10.3.0 及以上版本。插件版本 1.0.0。

[插件详情与下载](https://xielab2017.github.io/EasyMultiProfiler-Web-Plugins/examples/zotero-style-chat/) · [单独下载 plugin.json](https://xielab2017.github.io/EasyMultiProfiler-Web-Plugins/examples/zotero-style-chat/plugin.json)

## 安装与使用

1. 打开「模型与 API」，加载已配置的模型。
2. 打开「插件」，选择下载的 plugin.json，点击「启用」和「打开聊天」。
3. 在对话框加入 PDF、摘要或 Markdown，选择「要点」「研究方法」或「局限性」后发送。

设置可选择随屏幕大小、展开或收起。问答与 Agent 共用 EMP 的模型连接。启停保留当前浏览器保存的对话文字。需要 EMP 的 Python AI 服务和可用模型。

## 使用权限

chat.panel，使用 EMP 提供的研究对话窗口。
