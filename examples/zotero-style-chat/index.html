安装与使用

在线安装需要 EMP 10.4 或更高版本。安装按钮打开本机 8080 端口。使用其他地址时，直接从该实例的「插件」页安装。

  1. 在 EMP 10.4 或更高版本，打开「插件」，点击研究助手卡片的「安装并启用」。
  2. 在「模型与 API」加载已有的模型，然后在「插件」的已安装列表点击「打开聊天」。
  3. 在对话框加入 PDF、摘要或 Markdown，选择「要点」「研究方法」或「局限性」后发送。

设置可选择随屏幕大小、展开或收起。问答与 Agent 共用 EMP 的模型连接。启停保留当前浏览器保存的对话文字。需要 EMP 的 Python AI 服务和可用模型。

使用权限

chat.panel，使用 EMP 提供的研究对话窗口。
